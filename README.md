# Backend Projects

A collection of backend development projects built to strengthen
practical skills in **REST API development, authentication, databases,
backend architecture, and deployment**.

## Projects

### 1. Basecamp — Project Management Platform

A Node.js backend REST API focused on secure authentication and user
account management. It includes registration, login/logout, JWT-based
session handling, email verification, password recovery/reset, password
changes, and current-user management.

**Tech Stack:** Node.js, JavaScript, MongoDB, JWT, SMTP/Email Services,
REST API, npm

### 2. Scalable URL Shortening & Management API

A backend URL Shortener API that provides authenticated URL creation and
management, short-code redirection, and user-specific URL operations.
The project uses a modular architecture with validation, authentication
middleware, database integration, and production deployment.

**Tech Stack:** Node.js, Express.js, PostgreSQL, Drizzle ORM, JWT, Zod,
Docker, Vercel

## Purpose

These projects focus on practical backend engineering, including:

- RESTful API development
- Authentication and authorization
- Database integration and data modeling
- Request validation and error handling
- Modular backend architecture
- Docker-based local development
- API testing and documentation
- Production deployment
