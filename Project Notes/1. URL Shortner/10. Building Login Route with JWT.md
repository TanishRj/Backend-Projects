
Now we will create a login route

1. We will create a zod verification method under `request.validation.js`
```js
export const loginPostRequestBodySchema = z.object({
    email: z.string().email(),
    password: z.string().min(3),
})
```

2. Now we will import this verification under our main `user.routes.js` and create a validation result checking mechanism that checks if any results are there while validation from zod and returns error
```js
// Importing zod user, login validation schema
import {signupPostRequestBodySchema, loginPostRequestBodySchema} from '../validation/request.validation.js'

router.post('/login', async (req, res) => {

    // Checking email and password using zod

    const validationResult = await loginPostRequestBodySchema.safeParseAsync(req.body)

  

    // Checking if any error is returned in validation result

    if (validationResult.error) {

        return res.status(400).json({error: validationResult.error})

    }

})
```

3. Now we will make some changes in `hash.js` exported function which will include the `userSalt` which stores initial values as `undefined` but if provided with function `hashPasswordWithSalt()` use that salt
```js
export function hashPasswordWithSalt(password, userSalt = undefined){

    // Hashing password using crypto module

    const salt = userSalt ?? randomBytes(256).toString('hex')

    // Hashing password using generated salt

    const hashedPassword = createHmac('sha256', salt).update(password).digest('hex')

  

    return {salt, password: hashedPassword}

}
```

4. Continuing building our route before generation of jwt token

user.routes.js
```js
    // Getting data from validation

    const {email, password} = validationResult.data

  

    // Checking if user already exists

    const user = await getUserByEmail(email)

  

    // Returning response if user exists

    if (!user){

        return res.json(404).json({error: `User with email ${email} does not exists`})

    }

  

    // Getting password from validation and salt which is returned by getUserByEmail

    const {password: hashedPassword} = hashPasswordWithSalt(password, user.salt)

  

    // Checking if users password matches with the hashed password

    if(user.password !== hashedPassword){

        return res.status(400).json({message: `Invalid username or Password`})

    }
```

5. Now if a user is valid and gave valid credentials, we will generate token with JWT, we will install it using `pnpm i jsonwebtoken`, create a new variable for jwt secret in .env file : `JWT_SECRET=BadaAsaanSecet`, import the jwt and sign it using user id and jwt secret.

user.routes.js
```js
    // If password is correct, generate a token

    const token = jwt.sign({id: user.id}, process.env.JWT_SECRET)

    // Returning singed token

    return res.json({token})
```
