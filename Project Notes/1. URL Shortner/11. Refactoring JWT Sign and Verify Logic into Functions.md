
1. We will create a new file named `token.js` under `/utils` directory which will export a function which generates token using jwt and our secret

token.js
```js
// Importing jwt
import jwt from 'jsonwebtoken';

// Storing our secret value in JWT_SECRET variable
const JWT_SECRET = process.env.JWT_SECRET

// Creating and exporting a function which creates user token
export function createUserToken(payload){
    const token = jwt.sign(payload, JWT_SECRET)
    return token
}
```

2. Now we will validate our payload because we don't want anything to be sent in our payload, we only want to store id in our payload.

Creating new file named `token.validation.js` under `/validation` directory and apply validation using zod

token.validation.js
```js
// Importing z

import { z } from "zod";

  

// Exporting user token schema

export const userTokenSchema = z.object({

    id: z.string()

})
```

3. Now importing the exported `userTokenSchema` in `token.js` file and creating our final code with token validation

token.js
```js
// Importing jwt

import jwt from 'jsonwebtoken';

// Importing zod validation of token

import {userTokenSchema} from '../validation/token.validation.js'

  

// Storing our secret value in JWT_SECRET variable

const JWT_SECRET = process.env.JWT_SECRET

  

// Creating and exporting a function which creates user token

export async function createUserToken(payload){

    // Checking validation

    const validationResult = await userTokenSchema.safeParseAsync(payload)

    // if any error occurs, it throws a new error

    if(validationResult.error) throw new Error(validationResult.error.message)

    // If payload is valid

    const payloadValidatedData = validationResult.data

    const token = jwt.sign(payloadValidatedData, JWT_SECRET)

    return token

}
```


4. Now we will import the method in our main `user.routes.js` file and change the token generation mechanism

user.routes.js
```js
// Importing user token generation function
import {createUserToken} from '../utils/token.js'

// If password is correct, generate a token using new method
const token = await createUserToken({id: user.id})
```
