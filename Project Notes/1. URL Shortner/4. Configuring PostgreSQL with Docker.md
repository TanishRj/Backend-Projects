
1. First we will create `docker-compose.yml` in the root directory and write the below schema under the file
```js
services:

  db:

    image: postgres

    restart: always

    environment:

      POSTGRES_PASSWORD: 

      POSTGRES_USER: postgres

      POSTGRES_DB: postgres

    ports:

      - 5432:5432
```

Now we will spin up docker and create a new container using `docker compose up -d`
