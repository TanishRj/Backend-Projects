
1. Creating `package.json` with `pnpm init`
2. Installing node and express as dev dependencies  : `pnpm i @types/node @types/express -D`
3. Installing express : `pnpm i express`
4. Setting up basic express server with health route
```js
import express from 'express'

  

const app = express()

const PORT = process.env.PORT ?? 800

  

app.get('/', async (req, res) => {

    return res.json({status : `API Health OK`})

})

  

app.listen(PORT, () => {

    console.log(`Server is running on port ${PORT}`);

})
```

5. Now we will change our scripts in `package.json` and change the type to module
```json
"type": "module",

  "scripts": {

    "dev": "node --watch index"

  }
```
